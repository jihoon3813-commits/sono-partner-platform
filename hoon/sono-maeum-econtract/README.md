# 마음든든 모바일 전자계약

## 열기

ZIP을 압축 해제한 뒤 안티그래비티에서 `sono-maeum-econtract` 폴더를 엽니다. 별도 패키지 설치나 빌드 없이 `index.html`을 브라우저로 열면 상품 선택부터 진행할 수 있습니다.

도로명주소 검색은 인터넷 연결이 필요합니다. 로컬 웹 주소에서 확인하려면 이 폴더의 터미널에서 `python -m http.server 8000 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:8000/`을 엽니다.

## 편집할 파일

| 파일 | 내용 |
| --- | --- |
| index.html | 모바일 5단계 화면, 가입자·지정인 입력란, 상세주소, 결제수단, 동의, 서명 |
| assets/contract.css | 아이보리·딥그린 디자인, 본문 스크롤과 독립된 하단 버튼, 인쇄 스타일 |
| assets/contract.js | 생년월일 8자리 검증, 만 나이 표시, 도로명 검색, 화면 전환, 서명 및 계약서 미리보기 |
| reference/마음든든_전자계약서.pdf | 원본 양식 대조 및 향후 PDF 필드 배치에 사용할 첨부 계약서 |

## 수정본의 동작

- 가입자와 지정인의 생년월일은 YYYYMMDD 형식입니다. 지정인 성명은 수집하지 않습니다.
- 가입일을 한국 날짜로 계산해 지정인의 만 나이를 표시합니다. 만 80세는 지정할 수 있으며 81세 생일부터 진행이 차단됩니다.
- 도로명주소 검색 후 우편번호와 기본주소를 채우고 상세주소로 이동합니다. 검색이 어려우면 직접 입력할 수 있습니다.
- 계약서 미리보기에는 우편번호·도로명주소·상세주소, 지정인 관계와 만 나이가 반영됩니다.

## 운영 랜딩에 연결할 때

현재 결과물은 입력 및 미리보기를 위한 시안입니다. 마지막 버튼은 작성한 HTML 계약서를 브라우저 인쇄 화면에서 PDF로 저장합니다. 원본 PDF 자동 기입, 실제 계약 접수 및 결제 등록은 별도 연동 항목입니다.

기존 랜딩에 편입할 때는 `index.html`과 `assets/`의 상대 경로를 함께 유지합니다. 랜딩의 ‘전자계약 바로가기’는 배치한 계약 화면 주소에 연결하고, 계약 화면 상단의 ‘랜딩으로 돌아가기’는 기존 랜딩 주소에 연결합니다.
