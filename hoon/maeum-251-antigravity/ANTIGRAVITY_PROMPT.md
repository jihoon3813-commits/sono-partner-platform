# 안티그래비티에 전달할 작업 지시문

아래 내용을 안티그래비티 채팅에 붙여 넣어 주세요.

---

이 폴더는 소노아임레디 마음든든 상품의 홈페이지를 인계받은 프로젝트입니다. 먼저 README.md와 CONTENT_GUIDE.md를 읽고 현재 구현을 확인해 주세요.

`dist/index.html`에 HTML, CSS, JavaScript가 들어 있는 정적 단일 페이지입니다. `npm run dev`로 로컬 실행할 수 있으며 패키지 설치나 빌드가 필요하지 않습니다. 이미지 두 장과 인라인 SVG 아이콘이 포함되어 있습니다. 최초에는 현재 디자인과 기능을 그대로 실행하고 프로젝트 구조를 파악해 주세요. 프레임워크 교체나 디자인 재구성은 별도 요청이 있을 때 진행해 주세요.

현재 디자인 방향은 신뢰감 있는 딥그린·아이보리 색상, 가족 이미지, 큰 2·5·1 숫자, 아이콘과 인포그래픽, 배경색과 여백으로 명확히 구분되는 섹션입니다. 의전서비스와 기존·신규 멤버십까지 구현되어 있습니다. 반응형 디자인을 유지해 주세요.

상품을 수정할 때는 reference/의 원자료와 CONTENT_GUIDE.md를 확인해 주세요. 2·5·1은 총 8년간 매월 납입하는 구조이며, 2년만 납입하면 끝나는 상품으로 표현하면 안 됩니다. 공개 후기는 상품의 잔금 보장 이용 후기가 아닌 일반 장례서비스 사례입니다. 실제로 확인되지 않은 후기, 평점, 고객 수나 혜택 조건을 추가하지 마세요.

상담 영역은 현재 선택 조건을 화면에 요약하는 데모입니다. 실제 접수와 저장이 연결되기 전에는 접수 완료로 표시하지 마세요. 신규 멤버십은 2026-11-23 확대 예정이며 실제 개시 확인 없이 현재 제공 중이라고 바꾸지 마세요.

우선 실행 결과와 파일 구조를 확인하고, 후속 수정 요청을 받을 수 있는 상태로 준비해 주세요. 이후 수정 시에는 데스크톱과 모바일 화면, 계산기, 후기 필터, 상품 탭, FAQ, 가입 조건 요약을 점검해 주세요.
