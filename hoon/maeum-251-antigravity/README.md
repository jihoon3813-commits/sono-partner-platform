# 마음든든 · 안티그래비티 전달용

현재 사이트의 최신 저장 버전 5를 그대로 옮긴 소스입니다. 의전서비스, 전체 시각 디자인 개선, 기존·신규 멤버십 섹션까지 포함합니다.

- 내보낸 날짜: 2026-10-29 (한국 시간)
- 기준 사이트: https://maeum-251-guide.hoony365.chatgpt.site
- 원본 커밋: `6ffb1890ca8300cb0030a82ce51ad3103201510d`
- 형식: 정적 HTML + CSS + JavaScript, 반응형 단일 페이지
- `dist/`의 사이트 파일과 이미지 바이트는 원본과 동일합니다.

## 빠른 실행

1. ZIP을 압축 해제합니다.
2. 안티그래비티에서 `maeum-251-antigravity` 폴더를 엽니다.
3. Node.js가 설치된 환경의 터미널에서 실행합니다. 별도 패키지 설치는 필요 없습니다.

```bash
npm run dev
```

4. 브라우저에서 http://127.0.0.1:4173 을 엽니다.

Node.js가 없다면 Python으로도 실행할 수 있습니다.

```bash
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

간단히 확인하려면 `dist/index.html`을 브라우저에서 직접 열어도 됩니다. Noto Sans KR 웹폰트와 후기 원문 링크는 인터넷 연결을 사용하며, 웹폰트가 로드되지 않으면 시스템 기본 글꼴로 표시됩니다. 사이트의 두 PNG 이미지는 모두 포함되어 있습니다.

| 경로 | 용도 |

## 편집과 배포

- 핵심 수정 파일은 `dist/index.html`입니다. 빌드 도구나 프레임워크가 없으므로 저장 후 브라우저를 새로고침하면 반영됩니다.
- 유지보수를 위해 CSS·JavaScript를 별도 파일로 분리할 수 있지만, 처음 열 때는 현재 화면과 동작을 먼저 확인하세요.
- 정적 호스팅에는 **`dist/`의 내용만** 업로드합니다. 이 폴더 밖의 참고자료와 인수인계 문서는 공개 파일이 아닙니다.
- 이 ZIP은 독립적인 전달본입니다. 여기서 수정해도 기존 Sites 주소에 자동 반영되지 않습니다.
- 기존 사이트의 로그인·접근 제한은 호스팅 계층의 설정이며 이 정적 소스에 포함되지 않습니다. 별도 호스팅 시 공개 범위는 해당 환경에서 설정합니다.
