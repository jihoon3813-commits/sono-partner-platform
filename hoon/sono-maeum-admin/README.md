# 마음든든 영업관리 어드민

안티그래비티에서 이어서 작업할 수 있는 디자인 원본 패키지입니다.
현재 배포된 1차 디자인의 HTML·CSS·JavaScript를 그대로 포함했습니다.

## 가장 빠르게 확인하기

1. ZIP을 압축 해제합니다.
2. `sono-maeum-admin` 폴더의 `index.html`을 Chrome에서 엽니다.
3. 좌측 메뉴와 고객 목록, 우측 상세 패널을 눌러 화면을 확인합니다.

별도 설치나 빌드가 필요 없습니다. 인터넷에 연결되어 있으면 Pretendard 웹폰트를 불러옵니다. 미연결 상태에서는 시스템 폰트로 표시되어 글자 모양이 다를 수 있습니다.

## 안티그래비티에서 이어서 작업하기

1. 압축을 푼 `sono-maeum-admin` 폴더 전체를 프로젝트로 엽니다.
2. `ANTIGRAVITY_PROMPT.md`의 작업 지시문을 전달합니다.
3. 현재 화면을 먼저 실행한 뒤 필요한 변경 사항을 추가로 요청합니다.

폴더 안의 `AGENTS.md`는 디자인 유지와 작업 범위를 설명합니다. HTML 파일 하나만 전달하지 말고 CSS·JavaScript·문서를 포함한 폴더 전체를 사용하세요.

## 포함 파일

| 파일 | 용도 |
|---|---|
| index.html | 진입 화면과 공통 레이아웃 |
| styles.css | 딥그린·아이보리·세이지 스타일, PC·모바일 대응 |
| app.js | 11개 화면, 예시 데이터, 메뉴·필터·상세 패널 |
| ANTIGRAVITY_PROMPT.md | 작업 시작 시 전달할 지시문 |
| AGENTS.md | 디자인 유지 및 개발 범위 기준 |
| docs/SCREEN_MAP.md | 메뉴·주소·주요 화면 구성 |
| docs/HANDOFF.md | 구현된 범위와 추후 연동 항목 |
| docs/DESIGN_TOKENS.md | 색상·레이아웃·반응형 기준 |
| export-info.json | 원본 버전과 파일 해시 |

## 현재 범위

현재는 디자인 프로토타입입니다. 고객 검색·상태 필터·화면 이동·상세 탭·일부 폼 입력은 브라우저에서 확인할 수 있습니다.
실제 고객 DB, 로그인, 저장, 파일 업로드, 엑셀 생성, 본사 접수, 알림 발송, 수수료·환수 계산은 연결하지 않았습니다. 폼의 저장 버튼은 안내만 표시합니다.
고객명·연락처·파트너 조직·실적·일정은 가상 예시이며 실제 고객 정보와 인증 정보는 포함하지 않았습니다.

## 선택 사항: 로컬 서버

Python이 설치되어 있는 경우 프로젝트 폴더에서 `python -m http.server 5500`을 실행하고 `http://localhost:5500`으로 확인할 수 있습니다. Windows 환경에서는 `py -m http.server 5500`도 사용할 수 있습니다. 직접 HTML 파일을 여는 방식으로도 현재 프로토타입을 확인할 수 있습니다.
