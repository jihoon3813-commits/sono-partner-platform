# Project instructions

## 목적

소노아임레디 마음든든 영업관리 어드민 디자인. 현재는 디자인 검토용 정적 프로토타입이며 실제 운영 기능은 후속 요청 범위에서 개발한다.

## 작업 기준

- 현재 사용자 요청을 우선하고, 변경이 필요한 화면에 범위를 한정한다.
- index.html, styles.css, app.js를 진입점으로 사용한다. 임의로 프레임워크·빌드 도구를 추가하지 않는다.
- 기존 딥그린·아이보리·세이지 색상, 좌측 메뉴와 고객 상세 우측 전체 높이 패널을 유지한다.
- 모든 메뉴, 검색·필터, 상세 탭, PC·모바일 반응형을 보존한다.
- 디자인 예시와 실제 데이터를 구분한다. 개발 전 수치·실적·일정을 운영 현황으로 표시하지 않는다.
- 인증 정보와 실제 개인정보를 프런트엔드 소스에 넣지 않는다.
- 실제 저장·로그인·권한·업로드·본사 접수·발송·정산 기능은 별도 요구사항에 따라 연결한다.
- 서버 연동 시 인증과 조직별 접근 제어를 서버에서 적용한다. 화면 숨김만으로 접근 제어를 대신하지 않는다.
- 상품 및 수수료 조건은 최신 승인 자료 확인 후 반영한다. 현재 랜딩 참조 수치를 승인 조건으로 간주하지 않는다.
- 기존 사이트의 hosting 설정이나 인증정보는 이 패키지에 포함되어 있지 않다. 배포는 선택한 환경의 설정으로 별도 진행한다.

## 검증

JavaScript 수정 시 `node --check app.js`로 구문을 확인한다. 변경한 화면과 관련 이동 흐름을 PC·모바일에서 확인한다. 단순 문서 변경에는 기존 화면 테스트를 반복할 필요가 없다.
