# 개발 인수인계

## 포함된 동작

- 11개 화면 간 메뉴 이동과 해시 주소 처리
- 가상 고객 12명 검색, 상태·상품·파트너별 필터와 페이지 이동
- 고객 상세 패널과 고객 정보·상담 이력·녹취·서류 탭
- 파트너 조직 선택과 검색
- 연체 목록 상태 탭과 검색
- 주간·월간 예시 차트 전환
- 조회 기간 표시 변경
- 등록·설정 폼과 미리보기 안내
- 모바일 메뉴 열기·닫기

## 추후 연결 항목

| 영역 | 현재 | 기능 개발 시 연결할 내용 |
|---|---|---|
| 계정·권한 | 고정 관리자 표시 | 로그인, 세션, 역할·조직별 서버 접근 제어 |
| 고객 관리 | 가상 배열과 화면 필터 | 접수·배정·상담 이력·고객 상태의 영구 저장 |
| 상세 저장 | 안내 메시지만 표시 | 필드 검증, 변경 이력, 동시 수정 처리 |
| 파트너·입점 | 예시 조직·심사 화면 | 조직 관계, 신청, 승인·보완 절차 |
| 녹취·서류 | 자리 표시 | 권한별 업로드·조회·다운로드 |
| 엑셀 | 업로드·다운로드 버튼 UI | 양식 검증, 중복 검사, 검토 후 반영 |
| 본사 접수 | 연동 대기 표시 | 합의된 접수 규격·응답·오류 처리 |
| 연체 관리 | 예시 회차·상태 | 실제 납입 이력과 운영 정책 |
| 통계 | 고정 예시 수치 | 실제 기간·상태·유입별 집계 |
| 자료·프로모션 | 예시 카드 | 승인 자료 등록, 버전·게시 상태 관리 |
| 알림 | 예시 알림 UI | 수신자·발송 채널·발송 이력 |

위 항목은 다음 단계의 연결 목록이며 현재 구현되었다는 뜻이 아닙니다. 상세 정책은 후속 개발 요청에서 확정합니다.

## 상품 조건

상품 금액은 2026-11-16에 제공 랜딩에서 확인한 표시입니다. 최종 승인 자료와 대조 전이며 상품 화면에도 자료 대조 대기로 표시됩니다. 납입 완료와 만기 환급 시점은 구분되어야 합니다. 실제 수수료·보증금·환수 기준은 구현하지 않았습니다.

## 파일별 수정 위치

- index.html: 사이드바·상단 바·공통 패널 컨테이너
- styles.css: CSS 변수, 레이아웃, 표·카드·폼·패널, 반응형
- app.js: nav / titles 메뉴 정의, data / partners 예시 데이터, 각 화면 함수, showDrawer / openCustomer 상세, 클릭·입력 이벤트

## 인수인계 확인

디자인 원본은 2026-11-16에 PC·모바일과 주요 이동을 점검했습니다. 이번 ZIP은 원본 코드의 바이트 일치, JavaScript 구문, 상대 경로, ZIP 무결성을 확인했습니다. 신규 백엔드·실제 가입·외부 발송 테스트는 범위에 포함되지 않습니다.
