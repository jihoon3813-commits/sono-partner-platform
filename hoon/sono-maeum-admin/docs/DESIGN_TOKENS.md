## 반응형

- 1700px 이상: 콘텐츠 여백·차트·지표를 넓게 표시.
- 1250px 이하: 사이드바와 여백을 축소.
- 1050px 이하: 대시보드 주요 영역을 한 열로 전환.
- 800px 이하: 사이드바를 접고 햄버거 메뉴 사용, 지표 2열, 설정 메뉴 가로 배치.
- 480px 이하: 폼·자료·상품 흐름을 한 열로 표시.
- 넓은 고객 목록은 내부 가로 스크롤을 사용.

아이콘은 app.js의 인라인 SVG로 구성되어 별도 아이콘 라이브러리 설치가 필요하지 않습니다. 원본은 외부 이미지 파일을 사용하지 않습니다. 폰트 이외의 디자인 구성 요소는 패키지에 포함되어 있습니다.
