# 화면 구성

기본 진입 파일은 index.html이며 해시 주소로 화면을 전환합니다.

| 메뉴 | 주소 | 주요 구성 |
|---|---|---|
| 대시보드 | #dashboard | 핵심 지표 4개, 상담·가입 차트, 체크포인트, 최근 상담, 유입 경로 |
| 고객 관리 | #customers | 상태 탭, 이름·접수번호 검색, 상품·파트너 필터, 목록·페이지 이동 |
| 파트너 관리 | #partners | 파트너 지표, 조직 선택, 검색, 상세·등록 패널 |
| 입점 신청 | #applications | 신청 지표, 검토 목록, 신청서·체크리스트 |
| 연체 관리 | #overdue | 전체 가입 고객 기준 납입 현황, 연체·해결 상태 |
| 8월 이후 가입 고객 | #overdue-new | 가입 구간별 연체 관리 화면 예시 |
| 상품관리 | #products | 마음든든 3·4·5, 납입 구성, 2·5·1 안내, 상세 패널 |
| 프로모션 | #promotions | 캠페인 카드, 상세·등록 폼 |
| 통계 | #statistics | 상담·가입 차트, 상품별 가입, 파트너 실적 |
| 자료실 | #resources | 파일 카드, 수록 내용 예시, 등록 폼 |
| 환경설정 | #settings | 기본 정보, 사용자·권한, 알림 설정, 데이터 관리 |

## 공통 상세 패널

- 고객 상세: 고객 정보 / 상담 이력 / 녹취·서류
- 신규 고객 등록
- 파트너 상세 / 등록
- 입점 신청 상세
- 상품 정보
- 프로모션 상세 / 등록
- 자료 상세 / 등록
- 엑셀 업로드 화면
- 사용자 추가

PC 상세 패널은 우측에 상하 여백 없이 표시하고, 모바일에서는 전체 폭으로 확장합니다. 닫기·바깥 영역 클릭·Escape 키로 닫습니다.

## 화면 탐색 예시

대시보드 → 고객 관리 → 고객명 선택 → 상담 이력 탭 → 녹취·서류 탭.
파트너 관리 → 조직 선택 → 파트너 상세.
상품관리 → 마음든든 3·4·5 상세.
환경설정 → 사용자·권한 / 알림 설정.
